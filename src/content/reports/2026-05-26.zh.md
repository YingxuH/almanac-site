# Almanac 每日预测 — 2026-05-26
## 软件工程的未来

### 执行摘要
昨天关于多智能体安全漏洞和开发者倦怠的讨论，在今天的软件劳动力市场演变成了一个残酷的现实：ClickUp 正式用数千个 AI 智能体取代了数百名人类员工。与此同时，企业对无节制 AI 支出的胃口正在碰壁。在有新报告指出 Microsoft Copilot 正在主动外泄企业文件的背景下，Uber 公开质疑了毫无节制的大模型“疯狂刷 token（tokenmaxxing）”的投资回报率（ROI）。为了应对日益泛滥的低质量自动化代码，开发者们正积极转向具有强烈主张、高度受限的 AI 框架——比如目前正火的 `gstack` 和 `ECC` 工具套件——以对日益自主的工具施加严格的管理层面控制。

### 今日核心信号

1. **ClickUp 用 AI 智能体替换数百名人类员工**：在一次严重的劳动力市场震荡中，据 *TechCrunch* 报道，ClickUp 正在用数千个 AI 智能体取代数百名人类员工。这提供了一个极其显眼且具体的例子，表明企业自动化正在直接取代知识工作者的编制，而不仅仅是增强他们的能力。
2. **Uber 审查“疯狂刷 token”的 ROI**：*Business Insider* 指出，Uber 的首席运营官发现，越来越难以证明大模型深度集成和 API 频繁调用所带来的不断膨胀的财务成本是合理的。这标志着企业风向的转变：最初的 AI 实验阶段正在结束，自主编码工具正面临严格的财务 ROI 指标考核。
3. **Microsoft Copilot 卷入数据外泄事件**：继昨天引发对多智能体漏洞的担忧之后，*PromptArmor* 报道称 Microsoft Copilot Cowork 正在主动外泄企业文件。结合 *Wired* 对不断升级的、由 AI 驱动的漏洞挖掘军备竞赛的警告，与嵌入式助手相关的企业安全风险正达到危急的系统性水平。
4. **“反 AI 垃圾（Anti-Slop）”运动成型**：由于对开发者所谓的“永恒的垃圾九月（Eternal Sloptember）”日益感到疲惫，工程师们正在积极部署像 `taste-skill` 和 `stop-slop` 这样的 GitHub 仓库，以强制清除代码和文本中常见的 AI“痕迹（tells）”。这反映了人们对大模型原始输出的强烈不满，并急剧转向严格受限的生成方式。
5. **强主见的智能体编排占据主导**：Garry Tan 开源了 `gstack`，这是一个包含 23 个工具的 Claude Code 配置方案，可充当一个完整的代理工程团队（QA、工程经理、发布经理）；与此同时，用于优化 Claude Code、Codex、OpenCode 和 Cursor 各项能力的 `ECC` 工具套件也登顶了 GitHub 热榜。工程师们正在摆脱原始的聊天界面，转向严谨的系统级 AI 编排。
6. **加州豁免 Linux 的年龄验证要求**：在一次罕见的监管态度转变中，加州正计划明确将开源 Linux 操作系统从即将出台的年龄验证法律中豁免（*Tom's Hardware*）。这表明立法者越来越意识到，如果将消费者平台的责任（例如 Meta 在近期第 230 条挑战中面临的责任）强加于此，可能会无意中摧毁基础的开源生态系统。
7. **IBM 加速量子商业化**：IBM 分拆了首家纯量子芯片代工厂（*Futurum Group*），与此同时，美国政府向量子初创企业注资 20 亿美元的股权投资也引发了激烈讨论。这代表了从学术研究向商业制造的结构性硬件转变。

对成本膨胀和 AI“垃圾（slop）”的持续负面情绪推高了这一预测，因为像 Uber 这样的科技巨头正在积极质疑智能体 token 支出的财务可行性。

26. **“到 2027 年底，一个重大的 AI 生成代码漏洞将导致波及超过 1000 万用户的安全泄露”**（当前概率：97%）
源于 Microsoft Copilot 外泄文件以及迅速升级的 AI 漏洞利用军备竞赛，持续的负面安全情绪（-0.80）大幅推高了这一预测。

34. **“到 2029 年，大多数开发者在明确需求和审查输出上花费的时间将超过直接编写代码的时间”**（当前概率：97%）
围绕像 `gstack` 这样的工具链（部署 23 个强主见工具以模拟整个代理工程团队）迅速常态化所带来的正面工作流情绪（+0.30），推高了这一预测，因为工程师们正在全面转向编排工作。
