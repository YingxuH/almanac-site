# Almanac 每日预测 — 2026-06-03
## 软件工程的未来

### 执行摘要
继昨日安全情绪急剧收缩和监管焦虑之后，随着特朗普政府签署了一项缩减版的人工智能行政命令，缓解了联邦合规压力，今日的市场情绪发生了急剧反转。在微软发布全新“MAI”大模型系列（包括 MAI-Code-1-Flash 和 MAI-Thinking-1）以及独立的 GitHub Copilot App 的推动下，AI 编程领域迎来了大幅飙升（+0.80）。与此同时，Anthropic 通过“Project Glasswing”将 Claude Mythos 扩展至关键基础设施，企业信任度正在回升，这证明前沿大模型正在积极加强其安全态势，以应对高风险的部署场景。

### 今日核心信号

**1. 微软发布“MAI”大模型系列**
微软发布了七款全新的 AI 大模型，其中最引人注目的是 *MAI-Code-1-Flash* 和 *MAI-Thinking-1*。这标志着 AI 编程工具出现了战略分化：用于代码补全/内联生成的低延迟快速模型（Flash），搭配用于架构规划和调试的侧重推理的重度模型（Thinking）。
*来源：microsoft.ai/news/introducingmai-code-1-flash/*

**2. GitHub 将 Copilot 与 IDE 解绑**
GitHub 宣布推出独立版 *GitHub Copilot App* 的预览。通过打破传统 VS Code / Visual Studio 的边界，GitHub 正试图将 Copilot 的定位从单纯的 IDE 插件，转变为一个全局的、操作系统级别的助手，用于管理更广泛的开发者工作流和上下文。
*来源：github.com/features/preview/github-app*

**3. 开源权重模型打破对英伟达的依赖**
开发者成功在 AMD MI300X 加速器上运行了中国开源权重大模型 *DeepSeek-V4-Flash*。这表明开源 AI 生态系统的硬件抽象层正在快速成熟，确保了非美国模型能够高效扩展，而无需严格依赖英伟达的 CUDA 生态。
*来源：fergusfinn.com/blog/deepseek-v4-flash-mi300x/*

**4. Anthropic 将 Project Glasswing 扩展至关键基础设施**
Anthropic 正在扩展 *Project Glasswing*，将 Claude Mythos 部署到横跨 15 个国家的关键基础设施中。这直接反击了昨日关于 AI 智能体漏洞泛滥的论调，表明受到高度监管、对安全敏感的行业正开始将核心运营工作负载托付给前沿大模型实验室。
*来源：techcrunch.com/2026/06/02/anthropic-scales-claude-mythos...*

**5. 缩减版 AI 行政命令缓解监管逆风**
经过数周的反复，美国签署了一项大幅缩减的 AI 行政命令。联邦监管的回撤为 AI 基础设施提供商和编程初创公司带来了直接的喘息机会，将监管重担重新转移到了州一级的拉锯战上（例如昨日佛罗里达州的诉讼）。
*来源：politico.com/news/2026/06/02/trump-signs-downsized-ai-order*

**6. AI 智能体推动 RSS 自动化**
最新报告强调，RSS 正在经历复兴，成为自主 AI 智能体摄取互联网数据的首选媒介。随着网页抓取的环境变得越来越恶劣，像 RSS 这样的结构化信息流正在成为智能体信息收集和工作流自动化的主要 API。
*来源：julienreszka.com/blog/rss-is-back-ai-agents-are-reading-it/*

**7. Perplexity 重新将搜索定义为代码生成**
Perplexity 发表了关于“重新将搜索定义为代码生成”的研究，指出 AI 驱动的搜索引擎正越来越多地动态合成可执行代码，以向用户检索、解析和显示数据，这进一步模糊了软件工程与信息检索之间的界限。
*来源：research.perplexity.ai/articles/rethinking-search-as-code-generation*
